# buckler-home: the launcher

The Compose-for-TV Home that Buckler installs. The [README](../README.md) covers the CLI and
working on the project; [install.md](install.md) covers installing on a TV.

Compose-for-TV HOME (**0.20.0**) with a live header, a Main Stage, cover layouts, shelves, **Buckler Settings**, GitHub OTA prompts, and keyless Change cover (local + curated pack). Optional SteamGridDB / IGDB link via TV QR / device-code — not required for covers.

```bash
buckler home write                 # home-layout.json in the journals folder
buckler home push                  # adb push → buckler-home import on resume
buckler launcher build && buckler launcher install
```

**OTA:** publish a GitHub Release tagged `vX.Y.Z` with a `buckler-home*.apk` asset. For a **private** repo, link a fine-grained PAT in Buckler Settings → Updates (Contents + Releases read). Public repos need no token. No release / no auth → background check stays quiet; Check now explains.

**Covers:** [covers/index.json](../covers/index.json) and its artwork (`launcher/app/src/main/assets/covers/`, Apache-2.0 from dashboard-icons) are **bundled in the APK** — no third-party CDN at runtime. Refresh uses the GitHub Contents API when a token is linked, else raw URL, else bundled pack. Link enrichers in Settings → Appearance → App Thumbnails (SteamGridDB QR; IGDB needs `TWITCH_CLIENT_ID` + Device Code Grant).

**Long-press / Menu:** Open, Change cover, Remove (unpin), Uninstall, Info, Pin, **Move** (closes the menu; ◀ ▶ slide the app along Apps, OK places it, Back cancels).

**Buckler Settings**: a panel that slides in from the right over whatever is on screen, as SHIELD's own settings do, with Home (or the app) still in view, dimmed, behind it. One list at a time: OK goes into a row, Back comes out, and Back from the first list closes it. **Appearance**, **Screensaver** and **Clean up** open a list of their own, the section's own settings first as **Global**, then its pages. Choices are list rows, the current one marked with a dot, and changes show on Home behind the panel at once. It opens from the gear, a remote button remapped to it, or ≡ (Remote → ≡ → *Buckler Settings*). **Appearance** — Global (colour scheme and font), then a page for each part of Home, top to bottom — **Header** (what it shows, size, clock and date, its Weather, the News ticker, and the **Side Stage**: the mini stage in the middle of the header where Now Playing appears, and, while nothing plays, At a Glance or the companion if chosen), **Main Stage** (which widget, how tall, then that widget's own options) **Shelves** (tile layout, app size, names, shelf order and visibility, Up Next sources, Apps pins; Edit Home has the same) — and **App Thumbnails** (an icon pack, SteamGridDB / IGDB links, the curated pack, clearing custom thumbnails) — then Screensaver · Accessibility · Remote · Clean up · Updates · About (with shortcuts to Android TV's own screens). News and Weather appear in both the header and the Main Stage: each has **Sync across sections**, on by default, so changing sources, city or units in one changes both; switch it off and each part keeps its own (syncing again keeps the settings of the page you sync from). Each page shows only the options for what is switched on.

**Main Stage** sits under the header and stays put while the shelves scroll. Small / Medium / Large (Edit Home, or Settings → Appearance → Main Stage) sets how tall that band is, so the shelves keep a full row. Hold OK on it to switch News, Now Playing, Lyrics, Weather, Suggested, At a Glance, Calendar, Weather map, or Companion; under the choice are the showing widget's own quick options (News pace, Lyrics timing, Weather's span, which calendars, which companion) and **More in Settings** for the rest. The header's Side Stage is one D-pad stop: OK goes into its controls and Back comes out; holding OK on it (or any of its controls) opens the same kind of menu for it: Now Playing on or off, what shows while nothing plays, and that widget's options. **Lyrics** follows the header's Now Playing: word-timed lyrics from NetEase Cloud Music's YRC (an unofficial, keyless API; machine-split lines are treated as line-timed), else synced lyrics from [LRCLIB](https://lrclib.net) (open, no key), centred and filled letter by letter in the accent colour as each word is sung (a karaoke wipe), with a bouncing dot that lands on each word as it starts and settles on the last one. Word timings come from the lyrics when they carry them (enhanced LRC), otherwise they are spread over each line by syllable at the song's own pace, worked out from how tightly its lines are packed. Audio delay is allowed for automatically by route: Buckler checks where media is actually playing (a brief silent track, falling back to whether Android has A2DP on, since SHIELD bridges everything through an internal bus) on a background thread, then allows the platform's output latency plus 0.1 s on Bluetooth (about 0.2 s in all, calibrated by ear on SHIELD with a Bluetooth soundbar). Spotify reports its position about 0.19 s ahead of the audio it plays, so its lyrics are held back by that much too (measured with `scripts/lyrics_bench`, below). Settings → Appearance → Main Stage fine-tunes each route; ◀ ▶ on the stage nudge just the song playing, 0.1 s at a time, and are remembered for that song. Plain lyrics move through with the track, and video apps get a note instead. Weather can be the next hours or the next 10 days, with every card on one line. OK on it opens what it is showing: News opens the story in a reader (the article text, with page scripts left behind), Now Playing opens the app that is playing, Weather and Weather map open the weather app and Calendar the calendar app (the stage menu when there is none), and Suggested opens that title's app. News rotates every 30, 60, or 90 seconds (Settings → Appearance → Main Stage); ◀ ▶ step to the previous or next story. Every chosen source takes a turn, stories with a picture first, and feeds without pictures (CBS, DW, Al Jazeera…) use a text card.

**At a Glance, Calendar, Weather map and Companion** (Main Stage choices; At a Glance and the companion also fill the Side Stage while nothing plays):
- **At a Glance** picks what matters next by plain rules, with no ranking model and nothing promoted: an event under way or within 12 hours ("Dentist at 15:30 · in 2 h 30"), reminders due or overdue, "Rain likely from 16:00" or the day's range, sunrise or sunset when near, and tomorrow's first event in the evening.
- **Calendar** shows the next 3 or 4 days side by side with reminders beside them. Both read what the TV already syncs, so Buckler signs in to nothing: Android's calendar store (the Google account on the TV; DAVx⁵ for iCloud, Nextcloud, Fastmail and other CalDAV; ICSx⁵ for calendar links such as Proton's or Outlook's), the OpenTasks store that DAVx⁵ fills with CalDAV reminders, and Buckler's own reminders (Settings, with Today / Tonight / Tomorrow / Saturday / Someday). Google Calendar and Tasks can't be reached by a TV sign-in (Google's device flow doesn't allow those scopes), and Google Tasks has no Android store, so it isn't shown. Buckler's Extras clean-up turns Google Calendar Sync off; while a calendar widget is chosen the clean-up leaves it on, and Settings can turn it back on.
- **Weather map** draws pressure isobars every 4 hPa with blue H and red L centres, wind arrows and rain over Natural Earth's public-domain coastlines (`scripts/gen_coastlines.py`, 99 KB), from one keyless Open-Meteo request for a 13×7 grid around the city; ◀ ▶ step through the next 24 hours.
- **Companion** is a black cat, a fox, the Buckler shield or a window garden, drawn in code. It sleeps at night, wakes at dawn and keeps busy through the day, and shelters under an umbrella or a leaf when it rains. Snow, fog, thunder and overcast skies show too. It redraws at about 30 fps without recomposing, and stops while Home is hidden.

**Shelves:** press ◀ on the first tile of a shelf to reveal the shelf button. App size is Thin / Small / Medium / Large. An empty Up Next row is still a stop for ▲ ▼; OK does nothing there and ◀ reveals its shelf button like any other shelf. OK on the shelf button opens *Move shelf* (▲ ▼ reorder, OK places, Back cancels) and *Hide shelf*. Up Next also offers *Sources*, and each chosen app contributes at most three cards. Edit Home and Settings are the pencil and gear in the header. ▼ on the last shelf wraps to the rightmost header icon, and ▲ in the header wraps to the last shelf. Home cannot be left without a way back: the last shelf that is always drawn cannot be hidden, and Edit Home and Settings cannot both be switched off in the header. Each opens the other (Edit Home → *Settings*, Settings → Appearance → Shelves → *Open Edit Home*), so either icon reaches both. If nothing on Home leads to Settings anyway (header off, or no shelves), a **Home options** card at the end offers *Reset Home to Default* and *Open Settings*.

**Header** (Settings → Appearance → Header): one quiet row — logo, clock with date and weather (☀ 14°), a **Now Playing** mini player in the middle (the Side Stage) (only while something plays), then network icon (Wi-Fi / Ethernet → network settings), VPN icon (opens your VPN app, else VPN settings; the country code shows while a VPN is up) and Edit Home / Play Store / Settings icons — with a dim news ticker underneath. Every piece can be switched off on its own, or the whole header (Home then shows the Main Stage and shelves; the pencil and gear go with the header, and the Home options card takes their place). Clock in 12 h or 24 h and six date formats; weather from [Open-Meteo](https://open-meteo.com) (pick a city, no key); news from public RSS for UK, US, Europe, or Worldwide (plus gaming, business, and tech — one source or several; several are interleaved so each story is from the next source, with that source's mark in front) at Slow / Normal / Fast. Feeds are checked every 1, 2, 5, 12 or 24 hours (*Check for new stories every*, under News; 1 hour by default), only while Home is on screen: all at once, each asking for its feed only if it changed (ETag / Last-Modified), so an unchanged feed costs a short reply rather than a download. Each source's stories come newest first (BBC lists by importance, so its feed is re-sorted), stories over two days old are left out while a source keeps at least four, and the source with the newest story leads. A feed that fails keeps its last stories. The ticker scrolls only while Home is in front, and the last headlines are kept on disk with the time they were fetched, so after Android closes and restarts Home the ticker is not blank and fresh news is not fetched again. The News stage keeps the story it is showing when new headlines arrive, and loads the next story's picture ahead of time. Header size Thin / Medium / Large scales the logo, clock, icons and Now Playing together; Now Playing has the time played and the track's length and previous / play-pause / next; long songs, artists and albums scroll sideways, or are cut short with *Scroll long titles* off (Header → Side Stage, Main Stage → Now Playing, or either hold menu) or reduced motion. It needs media access: Header → Now Playing → *Grant media access*, or `buckler launcher media-access`. Android cannot embed another app's video in the launcher, so video apps show as a controllable session; apps that support picture-in-picture still float over Home in the system PiP window.

**Screensaver** (Settings → Screensaver): drifting clock, **DVD bounce**, **Now Playing** (album art for music, artwork for films and TV, the thumbnail and channel for YouTube, a LIVE card for Twitch and TiviMate; video apps drop their session when covered, so the last thing seen in the past 30 minutes is shown as paused), retro **3D Maze**, **3D Pipes**, **Mystify** and **Starfield** (drawn in code, no bundled art), online photos from any mix of Nature, Cityscape, Seascape, Landmarks, Sky & space and Wildlife (slides take turns between the ticked categories; Wikimedia Commons featured pictures, credited on screen), or **My photos**: upload from a phone via QR (Settings → Screensaver → My photos → Upload from phone) or `buckler launcher photos *.jpg`. Each screensaver has its own page in Screensaver's sidebar (after Global: which one is in use and Start after), with *Use this screensaver*, *Preview* and its own options, kept apart from the others: the drifting clock's size, date line and how often it moves; DVD bounce's speed, logo size, colour change and clock; online photos' categories, interval, transition (fade with a slow zoom, fade, or cut), credits and clock; My photos' uploads, interval, order (shuffle, oldest or newest first), transition and clock; Now Playing's blurred backdrop and corner clock; the Maze's speed, size and walls (brick, stone, wood or mixed); Pipes' speed and pipes at once; Mystify's speed, shapes and trail; Starfield's speed, number of stars and white or tinted stars. `buckler screensaver` makes it the system screensaver. **Start after** 60 / 90 / 120 s, 5 / 10 / 15 min, 1 hour, a custom time, or Off (changing it needs a one-time `buckler launcher grant-settings`).

**Appearance** (Settings → Appearance): colour scheme (**Buckler** teal and sage — the default — Light, Dark, Gruvbox, SNES UK, SNES US, SHIELD, and Buckler's own takes on ten popular editor and terminal schemes: Slate (One Dark), Velvet (Dracula), Ember (Monokai), Tidepool (Solarized Dark), Fjord (Nord), Marshmallow (Catppuccin), Neon (Tokyo Night), Graphite (GitHub Dark), Rosewood (Rosé Pine), Saffron (Ayu), each re-balanced for a TV and checked for contrast; shown three to a row; the app icon and TV banner follow the scheme via activity-aliases, regenerate them with `python scripts/gen_icons.py`), and font (System, Atkinson Hyperlegible, Condensed, Serif, Playful, Monospace, and ten popular Google Fonts: Inter, Montserrat, Poppins, Lato, Open Sans, Nunito, Raleway, Oswald, Playfair Display, Merriweather; SIL OFL, bundled in Regular and Bold, trimmed to Latin by `python scripts/gen_fonts.py`, licences in `launcher/branding/`). Home layout (Icon / Poster / Banner, shown as pictures) and app size (Thin / Small / Medium / Large, all layouts; stored as `tile_size` in the layout file) are in Edit Home.

**Accessibility** (Settings → Accessibility): high contrast, strong focus outline, reduced motion, spoken focus (text-to-speech reads the focused item), text size, and shortcuts to TalkBack and system captions; mono audio is a one-tap toggle once `grant-settings` has run.

**Remote** (Settings → Remote): the remote drawn in the theme with a line from each button to what it does, and a side view (the 2019 remote's back comes to a corner edge; the 2015 and 2017 remotes are flat). Buckler finds which remote is connected from NVIDIA's product id (2019: 0x7217, 2017: 0x7213, 2015: 0x7212, the same ids that name SHIELD's key layout files); *Your remote* overrides it, and *Other remote* gives a plain list for TV and third-party remotes. On the 2019 remote, Netflix, Back, Play/Pause, Rewind and Fast-forward each get a press, a double press and a hold: Default, Nothing, Buckler Settings, Recent apps, Home, Back, Play/Pause, Screensaver, Screenshot, Power menu, or any app (the 2015 and 2017 remotes' microphone button too). It works through an accessibility service Buckler switches on itself (it needs `grant-settings`); a button with nothing remapped passes straight through, and only a button with a double press waits 0.3 s for a second one. ≡ uses SHIELD's own *Customize menu button* options, which Buckler writes; its *Buckler Settings* is SHIELD's *Start any app* with Buckler, which opens the package's first TV entry, so the manifest declares BucklerSettingsActivity before MainActivity (Android lists a package's entries in the order of the activities they open). Power, Home and the 2019 remote's microphone never reach an app; volume is left to the TV or soundbar. Android stops the service if Buckler is force-stopped or crashes; Home then says so, and *Turn on again* restarts it (Buckler never edits Android's accessibility list on its own: on Android 11 doing that while Android is binding the service can restart the whole system).

**Missing shapes:** an app without a picture of the tile's shape gets one made from what it has, fitted whole on its own edge colour rather than cropped: a poster from its TV banner (no app ships a poster), or a banner or poster from its icon. The curated pack's square logos are letterboxed the same way.

**Icon packs** (Settings → Appearance → App Thumbnails): any installed launcher icon pack (the ADW / Nova `appfilter.xml` format) replaces each app's icon it has, matched by package and activity, or by the app's name when the pack lists only the phone app (Netflix's TV app gets the pack's `netflix`). With *Fill missing icons* (on) the rest are drawn to match the pack: Buckler measures the pack's own icons for apps on the TV (line width, line colour, how much of the icon the mark fills, and the backing layer of a layered pack like Lawnicons) and draws to those numbers, checking its result the same way. A pack that sets its own rule for unknown apps (`iconback`, `iconmask`, `iconupon`, `scale`) gets that rule instead, and in a full-colour pack without one, an app gets the pack's look: the shape its icons share (circle, squircle, rounded square), at their size, filled with the app's own background colour and its logo on top (a pack's own rule is used only when its icons share no shape); *Theme colour* leaves full-colour packs in their own colours. Home reloads its apps as soon as one is installed, updated or removed, so a newly installed app gets its pack or matched icon straight away. The drawing is each app's own logo traced as a thin, smooth (anti-aliased) line, or its initials in an outlined badge when the icon has no mark to trace; off, they keep their own icons. *Theme colour* paints a single-colour pack in the theme's text colour. Packs are not apps to open, so they stay out of the Library unless *Show in Library* is on, and each has an *Uninstall* button there; uninstalling the chosen pack goes back to apps' own icons. Phone icon packs are not in the TV's Play Store, so `buckler launcher iconpack install lawnicons` (Apache-2.0, about 23,000 apps, 19 MB) or `… install arcticons` (CC BY-SA 4.0 icons, about 49,000 apps, 71 MB) downloads one from its release page or F-Droid, checks it against the sha256 pinned in `src/buckler/data/catalog/iconpacks.yaml`, and installs it.

**Setup wizard**: opens on first run and again from Settings → Setup → *Run setup wizard*. *Simple* asks for the colour scheme, layout, shelves, screensaver and, on a SHIELD, Now Playing access, Buckler as the TV's screensaver (Backdrop off), icon packs and open apps, and three clean-up switches (Privacy and Extras on, Voice & Assistant off). *Advanced* adds the font, app-by-app clean-up, animation speed and Private DNS. It opens on the TV as it is now, so a second run changes only what you change, and *Review* lists exactly those changes before anything is applied. Icon packs (Lawnicons, Arcticons) and open apps (SmartTube, Moonlight, LocalSend, WireGuard, Tailscale, Nova) are the CLI's catalog: each is downloaded from its maker, checked against its pinned sha256 and installed over Network debugging with no prompt, and a swap takes its stock app's place in the Apps row (nothing stock is removed). The first SHIELD apply also compiles Buckler ahead of time, as `buckler tune` does. If granting Buckler's install permission restarts it, the wizard reopens at Review with your choices. After a system update that turns clean-up apps back on, Home says so once, and Settings → Setup lists them with *Turn them off again*; the wizard's Review offers the same.

**SHIELD changes from the TV** (the wizard, or Settings → Setup step by step): the changes `buckler setup` makes, made from the TV itself with no computer. With Network debugging on (Developer options), Buckler connects to the TV's own debugging service at 127.0.0.1 with a key it keeps privately; the TV asks once to *Allow* it (tick *Always allow*). It then grants Buckler's permissions (only the missing ones; Android restarts Buckler once if the install permission is among them), makes Buckler Home without disabling the stock launcher, and turns off the CLI's clean-up lists under the same never-touch rules, recording each app so *Restore everything* turns them back on. The lists are the CLI's own profiles, bundled by `python scripts/gen_profiles.py` (test_parity keeps them identical).

**Clean up** (Settings → Clean up): how much storage is free, how much apps take and how much of that is cache, Buckler's own cache (artwork, screensaver photos, headlines, web replies) with *Clear Buckler's cache*, and a shortcut to Android's storage settings. Its sidebar has **Apps** (below), **Cache** (apps holding more than 5 MB of cache, largest first, each opening its Android page where *Clear cache* is) and **Largest apps** (the 15 biggest, app plus saved data, to uninstall or clear). *Free cache space* there (or `buckler clean` from a computer) runs `pm trim-caches` over Network debugging and says how much it freed. Android clears only the part of each cache over that app's share, so an app's own page (its *Clear cache*) clears the rest. Sizes come from Android's storage records, under the same usage access as Apps.

**Apps** (Settings → Clean up → Apps): apps not opened for 14 / 30 / 60 / 90 days, from the TV's own usage records (nothing leaves the TV), busiest in the background first: how often each ran a background service and how much data it moved while off screen. Only apps with a launcher entry are judged; never Buckler, the keyboard, Home, accessibility services, apps installed within the period, or anything on the CLI's `never` list. Your own apps can be uninstalled from there; stock apps open Android's app page (Disable). *Keep* takes an app off the list. Returning Home names newly unused apps at most once a week (*Tell me on Home*). `buckler unused` prints the same list from a computer and `buckler unused --apply [PACKAGES]` disables them, journaled so `buckler restore` brings them back. Usage access is one of the `buckler launcher grant-settings` grants, along with self-updates installing without a prompt.

**DNS:** `buckler dns status` (alias `get`) / `set --hostname …` / `off`.

Package id: `dev.solon.bucklerhome`. CLI and launcher both track **0.20.0**. Uses `INTERNET` for artwork, curated pack, GitHub updates, header weather/news, online screensaver photos and optional linked APIs; `ACCESS_NETWORK_STATE` for the Wi-Fi / Ethernet / VPN icons — no ads, no account telemetry. Release APKs are signed with `launcher/keystore.properties` (`storeFile`, `storePassword`, `keyAlias`, `keyPassword`; git-ignored) when present, otherwise with the machine-local debug key — OTA updates only install over an APK signed with the same key. Buckler also checks a downloaded update itself before installing it: it must be `dev.solon.bucklerhome`, signed with the installed app's key, or it is deleted. Switching keys means one uninstall/reinstall. Backups are disabled (tokens live in encrypted prefs). Feeds and artwork must be `https://`.

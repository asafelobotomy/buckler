# buckler-home: the launcher

The Compose-for-TV Home that Buckler installs. The [README](../README.md) covers the CLI and
working on the project; [install.md](install.md) covers installing on a TV.

Compose-for-TV HOME (**0.22.0**) with a live header, a Main Stage, cover layouts, shelves, **Buckler Settings**, GitHub OTA prompts, and keyless Change cover (local + curated pack). Optional SteamGridDB / IGDB link via TV QR / device-code — not required for covers.

```bash
buckler home write                 # home-layout.json in the journals folder
buckler home push                  # adb push → buckler-home import on resume
buckler launcher build && buckler launcher install
```

**OTA:** publish a GitHub Release tagged `vX.Y.Z` with a `buckler-home*.apk` asset. For a **private** repo, link a fine-grained PAT in Buckler Settings → Accounts (Contents + Releases read). Public repos need no token. No release / no auth → background check stays quiet; Check now explains. A dev build (debug or `optimized`, or any APK not signed with the release key) never checks: the release can't install over it, and Check now says so.

**Covers:** [covers/index.json](../covers/index.json) and its artwork (`launcher/app/src/main/assets/covers/`, Apache-2.0 from dashboard-icons) are **bundled in the APK** — no third-party CDN at runtime. Refresh uses the GitHub Contents API when a token is linked, else raw URL, else bundled pack. Link enrichers in Settings → Accounts (SteamGridDB QR; IGDB needs `TWITCH_CLIENT_ID` + Device Code Grant).

**Long-press / Menu:** Open, Change cover, Remove (unpin), Uninstall, Info, Pin, **Move** (closes the menu; ◀ ▶ slide the app along Apps, OK places it, Back cancels).

**Buckler Settings**: a panel that slides in from the right over whatever is on screen, as SHIELD's own settings do, with Home (or the app) still in view, dimmed, behind it. One list at a time: OK goes into a row, Back comes out, and Back from the first list closes it; coming back puts focus on the row you left from. It opens from the gear, a remote button remapped to it, or ≡ (Remote & accessories → ≡ → *Buckler Settings*). Buckler's settings and the TV's are one list, by topic: **Appearance** · **Widgets** · **bucklerStore** · **Screensaver** · **Display & sound** · **Power** · **Remote & accessories** · **Network** · **Accessibility** · **Apps & storage** · **Device** · **Accounts** · **Updates** · **About**. Each page holds Buckler's rows and Android's side by side; a row marked ↗ opens Android's own screen, for what Buckler cannot set itself. A section with pages opens a list of its own, its own settings first as **Global** (**Overview** for Apps & storage), then its pages. Rows follow SHIELD's lists: a setting that is on or off shows **On** / **Off** on the right; a choice shows its current value and › and opens a short list with ● on the current one (choosing comes back); where several can be chosen together (header items, news sources, calendars, photo categories) each is ticked ✓. Changes show on Home behind the panel at once, and each page shows only the options for what is switched on. **Appearance**: Global (colour scheme, font, 12/24-hour clock and date format, which the screensaver clock and weather times use too), then a page for each part of Home, top to bottom: **Header** (on or off, what it shows, size, and the **Side Stage**: the mini stage in the middle of the header where Now Playing appears, and what it shows while nothing plays), **Main Stage** (which widget and how tall, with a row to that widget's page), **Shelves** (tile layout, app size, names, shelf order and visibility, Up Next sources, Apps pins; Edit Home has the same) and **Icons & artwork** (an icon pack, the curated pack, clearing custom thumbnails). **Widgets**: Global (media access, and which widgets are where), then **Weather**, **News**, **Calendar & reminders**, **Now Playing & Lyrics**, **Multiview** and **Companion**, each wherever on Home it shows; Header and Main Stage link to them. News and Weather appear in both the header and the Main Stage: *Same city* / *Same sources*, on by default, keeps one set for both; off, each place has its own. **Screensaver** links to Power's *Sleep after*; **Accessibility** is grouped by Seeing, Motion, Speech and Hearing, each with Buckler's rows (on Home) beside the TV's (in apps): text size (other apps restart to take it), high contrast, reduced motion and animation speed, spoken focus, speech rate and TalkBack, mono audio and captions (on, size, style). The TV's rows write Android's own settings, which apply at once; they need the one-time `buckler launcher grant-settings` and say so until it has run. Android refuses apps its private keys (mono audio, text size) whatever they hold, so those, the time zone, Sleep, Restart and the app page's actions go over Network debugging, as SHIELD clean-up does. Buckler's clock follows the TV's 12/24-hour setting, and choosing it in Buckler sets the TV's too. **Remote & accessories**: the drawn remote, with a page for each button (Press, Double press, Hold). **Network**: Private DNS (the wizard's choices), and Android's screen for Wi-Fi, Ethernet and proxy. **Display & sound**: system sounds, surround sound (Automatic, Always, Never) and the HDMI-CEC switches (CEC itself and volume over CEC; turning the TV on and off with SHIELD is under Power), and Android's screen for resolution. **Power**: Sleep now and Restart (pressed twice), *Sleep after* and *Stay awake on music*, and turning the TV on and off with SHIELD over HDMI-CEC (Android's own Power screen has only Sleep and Restart). **Device**: date & time (automatic date and time zone, the time zone by hand on Android 11, 12/24-hour clock), the keyboard in use, which keyboards are on, and autofill; All of Android's settings ↗; then the setup wizard, Network debugging, both Developer options screens, Buckler's permissions and Make Buckler Home; **SHIELD clean-up** beside it turns the clean-up profiles off, and back on. **Accounts**: every sign-in in one place (GitHub, SteamGridDB, IGDB, Jellyfin, Stremio), plus Android's screen for the TV's own accounts. **Updates**: Buckler's, and SHIELD's system update ↗. **About**: version, credits, About this TV ↗.

**Main Stage** sits under the header and stays put while the shelves scroll. Small / Medium / Large (Edit Home, or Settings → Appearance → Main Stage) sets how tall that band is, so the shelves keep a full row. Hold OK on it to switch News, Now Playing, Lyrics, Weather, Suggested, At a Glance, Calendar, Weather map, Companion, Multiview, Comics or Spurious correlations; under the choice are the showing widget's own quick options (News pace, Lyrics timing, Weather's span, which calendars, which companion, how often Comics and Spurious correlations move on) and **More in Settings** for the rest. The header's Side Stage is one D-pad stop: OK goes into its controls and Back comes out; holding OK on it (or any of its controls) opens the same kind of menu for it: Now Playing on or off, what shows while nothing plays, and that widget's options. **Lyrics** follows the header's Now Playing: word-timed lyrics from NetEase Cloud Music's YRC (an unofficial, keyless API; machine-split lines are treated as line-timed), else synced lyrics from [LRCLIB](https://lrclib.net) (open, no key), centred and filled letter by letter in the accent colour as each word is sung (a karaoke wipe), with a bouncing dot that lands on each word as it starts and settles on the last one. Word timings come from the lyrics when they carry them (enhanced LRC), otherwise they are spread over each line by syllable at the song's own pace, worked out from how tightly its lines are packed. Audio delay is allowed for automatically by route: Buckler checks where media is actually playing (a brief silent track, falling back to whether Android has A2DP on, since SHIELD bridges everything through an internal bus) on a background thread, then allows the platform's output latency plus 0.1 s on Bluetooth (about 0.2 s in all, calibrated by ear on SHIELD with a Bluetooth soundbar). Spotify reports its position about 0.19 s ahead of the audio it plays, so its lyrics are held back by that much too (measured with `scripts/lyrics_bench`, below). Settings → Widgets → Now Playing & Lyrics fine-tunes each route; ◀ ▶ on the stage nudge just the song playing, 0.1 s at a time, and are remembered for that song. Plain lyrics move through with the track, and video apps get a note instead. Weather can be the next hours or the next 10 days, with every card on one line; the hours are on the TV's clock even for a city in another time zone, and an hour that has gone by since the last fetch drops off. OK on it opens what it is showing: News opens the story in a reader (the article text, with page scripts left behind), Now Playing opens the app that is playing, Weather and Weather map open the weather app and Calendar the calendar app (the stage menu when there is none), and Suggested opens that title's app. **Multiview** puts up to three videos side by side on the Main Stage, all playing, with sound only from the highlighted one (it takes audio focus; none while focus is elsewhere). OK plays a tile full screen with the player's controls, from where it had got to; Back returns. They come from Jellyfin (Continue watching, Next up and Latest, played as the file is, with no transcoding, so three stay light on the server; sign in with Quick Connect, so no password is typed on the TV, or name and password; servers are found on the network or typed), Stremio (sign in with a code approved on a phone, or its QR code; your Continue watching, played from the first direct link your installed add-ons give, such as a debrid service's; torrent streams need Stremio's own engine, so those stay in the Stremio app, and the tile says so), an IPTV playlist (M3U, searched by name) or cameras and other streams added by address (RTSP, HLS, http). Settings → Widgets → Multiview sets the tiles and sources (Jellyfin and Stremio sign in under Settings → Accounts); addresses and the Jellyfin and Stremio sign-ins are kept encrypted. The players stop while Home is hidden, so an app opened over it gets the video decoders back. News rotates every 30, 60, or 90 seconds (Settings → Widgets → News); ◀ ▶ step to the previous or next story. Every chosen source takes a turn, stories with a picture first, and feeds without pictures (CBS, DW, Al Jazeera…) use a text card.

**At a Glance, Calendar, Weather map, Companion, Comics and Spurious correlations** (Main Stage choices; At a Glance and the companion also fill the Side Stage while nothing plays):
- **At a Glance** picks what matters next by plain rules, with no ranking model and nothing promoted: an event under way or within 12 hours ("Dentist at 15:30 · in 2 h 30", "Flight tomorrow at 07:00 · in 11 h" late in the evening), all-day events on every day they span, reminders due or overdue ("3 reminders (1 overdue)"), "Rain likely from 16:00" (or "this hour") or the day's range, sunrise or sunset when near, and tomorrow's first event in the evening (not repeating the one already shown). It re-reads the calendar and reminders as soon as they change in Settings, and says when calendar access is missing. In the Side Stage it stays a stop (with its menu) even when it has nothing to say.
- **Calendar** shows the next 3 or 4 days side by side with reminders beside them. Both read what the TV already syncs, so Buckler signs in to nothing: Android's calendar store (the Google account on the TV; DAVx⁵ for iCloud, Nextcloud, Fastmail and other CalDAV; ICSx⁵ for calendar links such as Proton's or Outlook's), the OpenTasks store that DAVx⁵ fills with CalDAV reminders, and Buckler's own reminders (Settings, with Today / Tonight / Tomorrow / Saturday / Someday). Google Calendar and Tasks can't be reached by a TV sign-in (Google's device flow doesn't allow those scopes), and Google Tasks has no Android store, so it isn't shown. Buckler's Extras clean-up turns Google Calendar Sync off; while a calendar widget is chosen the clean-up leaves it on, and Settings can turn it back on.
- **Weather map** draws pressure isobars every 4 hPa with blue H and red L centres, wind arrows and rain over Natural Earth's public-domain coastlines (`scripts/gen_coastlines.py`, 99 KB), from one keyless Open-Meteo request for a 13×7 grid around the city (temperature too, for the screensaver's heat map); ◀ ▶ step through the next 24 hours.
- **Comics** shows newspaper strips from the 1910s and 1920s whose US copyright has run out (Wikimedia Commons files tagged PD-US-expired that a "comic strip" search finds; only daily strips, about 3:1, since a Sunday page is unreadable in the band), credited above the strip. A new one every 1, 2 (default), 5, 10 or 30 minutes; ◀ ▶ and OK step through them. The list is cached for three days and the strips in the screensaver's photo cache, each downloaded with Buckler's user agent as Wikimedia asks.
- **Spurious correlations** shows one of Tyler Vigen's [spurious correlations](https://www.tylervigen.com/spurious-correlations) (CC BY 4.0, credited on the card): two unrelated yearly series that rose and fell together, drawn as a blue and a red line (each on its own scale, a dot on each year) with the first and last year and r under them. The two names share one size, the largest at which both fit whole (up to 18, 20 or 24 sp on a Small, Medium or Large stage, down to 11 sp), so a long name wraps or shrinks but is never cut short. Buckler reads the site's random page (title and data table; there is no API), every 10 minutes by default (1–30), keeping the last 12 on disk so going in and out of an app neither blanks it nor fetches again; ◀ ▶ step back through them, and ▶ on the newest (or OK) fetches another. Settings → Widgets → Comics & correlations sets both paces.
- **Companion** is a black cat, a fox, the Buckler shield or a window garden, drawn in code. It sleeps at night, wakes at dawn and keeps busy through the day, and shelters under an umbrella or a leaf when it rains. Snow, fog, thunder and overcast skies show too. It redraws at about 30 fps without recomposing, and stops while Home is hidden.

**Shelves:** press ◀ on the first tile of a shelf to reveal the shelf button. App size is Thin / Small / Medium / Large. An empty Up Next row is still a stop for ▲ ▼; OK does nothing there and ◀ reveals its shelf button like any other shelf. OK on the shelf button opens *Move shelf* (▲ ▼ reorder, OK places, Back cancels) and *Hide shelf*. Up Next also offers *Sources*, and each chosen app contributes at most three cards. Edit Home and Settings are the pencil and gear in the header. ▼ on the last shelf wraps to the rightmost header icon, and ▲ in the header wraps to the last shelf. Home cannot be left without a way back: the last shelf that is always drawn cannot be hidden, and Edit Home and Settings cannot both be switched off in the header. Each opens the other (Edit Home → *Settings*, Settings → Appearance → Shelves → *Open Edit Home*), so either icon reaches both. If nothing on Home leads to Settings anyway (header off, or no shelves), a **Home options** card at the end offers *Reset Home to Default* and *Open Settings*.

**Header** (Settings → Appearance → Header): one quiet row — logo, clock with date and weather (☀ 14°), a **Now Playing** mini player in the middle (the Side Stage) (only while something plays), then network icon (Wi-Fi / Ethernet → network settings), VPN icon (opens your VPN app, else VPN settings; the country code shows while a VPN is up) and Edit Home / Play Store / Settings icons — with a dim news ticker underneath. Every piece can be switched off on its own, or the whole header (Home then shows the Main Stage and shelves; the pencil and gear go with the header, and the Home options card takes their place). Clock in 12 h or 24 h and six date formats; weather from [Open-Meteo](https://open-meteo.com) (pick a city, no key); news from public RSS for UK, US, Europe, or Worldwide (plus gaming, business, and tech — one source or several; several are interleaved so each story is from the next source, with that source's mark in front) at Slow / Normal / Fast, scrolling or one story at a time (*Ticker*, under News; one at a time holds each story for that speed's time: 14, 9 or 5 s). Feeds are checked every 1, 2, 5, 12 or 24 hours (*Check for new stories every*, under News; 1 hour by default), only while Home is on screen: all at once, each asking for its feed only if it changed (ETag / Last-Modified), so an unchanged feed costs a short reply rather than a download. Each source's stories come newest first (BBC lists by importance, so its feed is re-sorted), stories over two days old are left out while a source keeps at least four, and the source with the newest story leads. A feed that fails keeps its last stories. The ticker scrolls only while Home is in front, and the last headlines are kept on disk with the time they were fetched, so after Android closes and restarts Home the ticker is not blank and fresh news is not fetched again. The News stage keeps the story it is showing when new headlines arrive, and loads the next story's picture ahead of time. Header size Thin / Medium / Large scales the logo, clock, icons and Now Playing together; Now Playing has the time played and the track's length and previous / play-pause / next; long songs, artists and albums scroll sideways, or are cut short with *Scroll long titles* off (Header → Side Stage, Main Stage → Now Playing, or either hold menu) or reduced motion. It needs media access: *Grant media access* (Settings → Widgets, or anywhere Now Playing asks for it) turns it on in place over Network debugging, or `buckler launcher media-access` from a computer. Android cannot embed another app's video in the launcher, so video apps show as a controllable session; apps that support picture-in-picture still float over Home in the system PiP window.

**Screensaver** (Settings → Screensaver): drifting clock, **DVD bounce**, **Now Playing** (album art for music, artwork for films and TV, the thumbnail and channel for YouTube, a LIVE card for Twitch and TiviMate; video apps drop their session when covered, so the last thing seen in the past 30 minutes is shown as paused), retro **3D Maze**, **3D Pipes**, **Mystify** and **Starfield** (drawn in code, no bundled art), **Rolling weather** (the weather at Home's city in turn: now with the day's range, rain and the sun, the next 8 hours, the next 7 days, the pressure map with wind and rain, and a temperature heat map over the same coastlines; every slide fades in nudged a little so nothing burns in, and the weather is refetched every half hour), online photos from any mix of Nature, Cityscape, Seascape, Landmarks, Sky & space and Wildlife (slides take turns between the ticked categories; Wikimedia Commons featured pictures, credited on screen), or **My photos**: upload from a phone via QR (Settings → Screensaver → My photos → Upload from phone) or `buckler launcher photos *.jpg`. Each screensaver has its own page in Screensaver's sidebar (after Global: which one is in use and Start after), with *Use this screensaver*, *Preview* and its own options, kept apart from the others: the drifting clock's size, date line and how often it moves; DVD bounce's speed, logo size, colour change and clock; online photos' categories, interval, transition (fade with a slow zoom, fade, or cut), credits and clock; My photos' uploads, interval, order (shuffle, oldest or newest first), transition and clock; Now Playing's blurred backdrop and corner clock; the Maze's speed, size and walls (brick, stone, wood or mixed); Pipes' speed and pipes at once; Mystify's speed, shapes and trail; Starfield's speed, number of stars and white or tinted stars; Rolling weather's slides (forecast and maps, forecast only, or maps only), interval and clock. `buckler screensaver` makes it the system screensaver. **Start after** 60 / 90 / 120 s, 5 / 10 / 15 min, 1 hour, a custom time, or Off (changing it needs a one-time `buckler launcher grant-settings`).

**Appearance** (Settings → Appearance): colour scheme (**Buckler** teal and sage — the default — Light, Dark, Gruvbox, SNES UK, SNES US, SHIELD, and Buckler's own takes on ten popular editor and terminal schemes: Slate (One Dark), Velvet (Dracula), Ember (Monokai), Tidepool (Solarized Dark), Fjord (Nord), Marshmallow (Catppuccin), Neon (Tokyo Night), Graphite (GitHub Dark), Rosewood (Rosé Pine), Saffron (Ayu), each re-balanced for a TV and checked for contrast; shown three to a row; the app icon and TV banner follow the scheme via activity-aliases, regenerate them with `python scripts/gen_icons.py`), and font (System, Atkinson Hyperlegible, Condensed, Serif, Playful, Monospace, and ten popular Google Fonts: Inter, Montserrat, Poppins, Lato, Open Sans, Nunito, Raleway, Oswald, Playfair Display, Merriweather; SIL OFL, bundled in Regular and Bold, trimmed to Latin by `python scripts/gen_fonts.py`, licences in `launcher/branding/`). Home layout (Icon / Poster / Banner, shown as pictures) and app size (Thin / Small / Medium / Large, all layouts; stored as `tile_size` in the layout file) are in Edit Home and Settings → Appearance → Shelves.

**Accessibility** (Settings → Accessibility): by topic, with Buckler's rows beside the TV's. Seeing: text size on Home and in apps, high contrast on Home and in apps, strong focus outline. Motion: reduced motion on Home, animation speed in apps. Speech: spoken focus (text-to-speech reads the focused item), speech rate, TalkBack ↗. Hearing: mono audio and captions.

**Remote** (Settings → Remote & accessories): the remote drawn in the theme with a line from each button to what it does, and a side view (the 2019 remote's back comes to a corner edge; the 2015 and 2017 remotes are flat). Buckler finds which remote is connected from NVIDIA's product id (2019: 0x7217, 2017: 0x7213, 2015: 0x7212, the same ids that name SHIELD's key layout files); *Your remote* overrides it, and *Other remote* gives a plain list for TV and third-party remotes. On the 2019 remote, Netflix, Back, Play/Pause, Rewind and Fast-forward each get a press, a double press and a hold: Default, Nothing, Buckler Settings, Recent apps, Home, Back, Play/Pause, Screensaver, Screenshot, Power menu, or any app (the 2015 and 2017 remotes' microphone button too). It works through an accessibility service Buckler switches on itself (it needs `grant-settings`); a button with nothing remapped passes straight through, and only a button with a double press waits 0.3 s for a second one. ≡ uses SHIELD's own *Customize menu button* options, which Buckler writes; its *Buckler Settings* is SHIELD's *Start any app* with Buckler, which opens the package's first TV entry, so the manifest declares BucklerSettingsActivity before MainActivity (Android lists a package's entries in the order of the activities they open). Power, Home and the 2019 remote's microphone never reach an app; volume is left to the TV or soundbar. The service runs in a small process of its own (`:remote`, about 11 MB), so a crash in Home leaves the remote working, and an update keeps it on (Android binds it again itself). A force-stop (Settings → Force stop, `am force-stop`, or Android after repeated crashes) takes it off Android's accessibility list; Buckler, restarted at once as Home, puts it back by itself 10 s later (60 s just after boot), waiting so it never edits the list while Android is still binding the service (on Android 11 that can bind it twice or restart the whole system). Only if that fails does Home say so, with *Turn on again* in Settings → Remote. Turning it off in Android's own Accessibility settings is respected: Buckler brings it back only once it has been turned on again, there or in Settings → Remote.

**Missing shapes:** an app without a picture of the tile's shape gets one made from what it has, fitted whole on its own edge colour rather than cropped: a poster from its TV banner (no app ships a poster), or a banner or poster from its icon. The curated pack's square logos are letterboxed the same way.

**Icon packs** (Settings → Appearance → Icons & artwork): any installed launcher icon pack (the ADW / Nova `appfilter.xml` format) replaces each app's icon it has, matched by package and activity, or by the app's name when the pack lists only the phone app (Netflix's TV app gets the pack's `netflix`). With *Fill missing icons* (on) the rest are drawn to match the pack: Buckler measures the pack's own icons for apps on the TV (line width, line colour, how much of the icon the mark fills, and the backing layer of a layered pack like Lawnicons) and draws to those numbers, checking its result the same way. A pack that sets its own rule for unknown apps (`iconback`, `iconmask`, `iconupon`, `scale`) gets that rule instead, and in a full-colour pack without one, an app gets the pack's look: the shape its icons share (circle, squircle, rounded square), at their size, filled with the app's own background colour and its logo on top (a pack's own rule is used only when its icons share no shape); *Theme colour* leaves full-colour packs in their own colours. Home reloads its apps as soon as one is installed, updated or removed, so a newly installed app gets its pack or matched icon straight away. The drawing is each app's own logo traced as a thin, smooth (anti-aliased) line, or its initials in an outlined badge when the icon has no mark to trace; off, they keep their own icons. *Theme colour* paints a single-colour pack in the theme's text colour. Packs are not apps to open, so they stay out of the Library unless *Show in Library* is on, and each has an *Uninstall* button there; uninstalling the chosen pack goes back to apps' own icons. Phone icon packs are not in the TV's Play Store, so `buckler launcher iconpack install lawnicons` (Apache-2.0, about 23,000 apps, 19 MB) or `… install arcticons` (CC BY-SA 4.0 icons, about 49,000 apps, 71 MB) downloads one from its release page or F-Droid, checks it against the sha256 pinned in `src/buckler/data/catalog/iconpacks.yaml`, and installs it.

**bucklerStore** (Settings → bucklerStore, or `buckler store` from a computer): add-ons from [asafelobotomy/bucklerStore](https://github.com/asafelobotomy/bucklerStore), whose `index.json` Buckler fetches once per Settings visit (a copy is bundled, so it works offline). **Widgets**: Buckler's own Main Stage widgets, each added or removed from the Main Stage's choices (At a Glance and Companion from the Side Stage's too; a widget on screen cannot be removed until another is chosen). News, Now Playing, Weather and Suggested come added; Lyrics, At a Glance, Calendar, Weather map, Companion and Multiview are added from the store, and on the first start with the store any of them already on screen stays added. New widgets arrive with Buckler updates. **Colour schemes** and **Fonts** (SIL OFL, Regular and Bold trimmed to Latin) install into `Android/data/dev.solon.bucklerhome/files/store/` and join Appearance's pickers after the built-in ones; removing the one in use goes back to the built-in choice. **Icon packs** are downloaded and handed to Android, which asks to confirm. Every download is checked against the sha256 in the index, an icon pack also against its package name. `buckler store list`, `install <id>…`, `remove <id>…` and `installed` do the same over Network debugging; Buckler picks up what they put on the TV the next time its Settings comes to the front.

**Setup wizard**: opens on first run and again from Settings → Device → *Run setup wizard*. *Simple* asks for the colour scheme, layout, shelves, screensaver and, on a SHIELD, Now Playing access, Buckler as the TV's screensaver (Backdrop off), icon packs and open apps, and three clean-up switches (Privacy and Extras on, Voice & Assistant off). *Advanced* adds the font, app-by-app clean-up, animation speed and Private DNS. It opens on the TV as it is now, so a second run changes only what you change, and *Review* lists exactly those changes before anything is applied. Icon packs (Lawnicons, Arcticons) and open apps (SmartTube, Moonlight, LocalSend, WireGuard, Tailscale, Nova) are the CLI's catalog: each is downloaded from its maker, checked against its pinned sha256 and installed over Network debugging with no prompt, and a swap takes its stock app's place in the Apps row (nothing stock is removed). The first SHIELD apply also compiles Buckler ahead of time, as `buckler tune` does. If granting Buckler's install permission restarts it, the wizard reopens at Review with your choices. After a system update that turns clean-up apps back on, Home says so once, and Settings → Device → SHIELD clean-up lists them with *Turn them off again*; the wizard's Review offers the same.

**SHIELD changes from the TV** (the wizard, or Settings → Device, and Device → SHIELD clean-up): the changes `buckler setup` makes, made from the TV itself with no computer. With Network debugging on (Developer options), Buckler connects to the TV's own debugging service at 127.0.0.1 with a key it keeps privately; the TV asks once to *Allow* it (tick *Always allow*). It then grants Buckler's permissions (only the missing ones; Android restarts Buckler once if the install permission is among them), makes Buckler Home without disabling the stock launcher, and turns off the CLI's clean-up lists under the same never-touch rules, recording each app so *Restore everything* turns them back on. The lists are the CLI's own profiles, bundled by `python scripts/gen_profiles.py` (test_parity keeps them identical).

**Apps & storage** (Settings → Apps & storage, Overview): how much storage is free, how much apps take and how much of that is cache, Buckler's own cache (artwork, screensaver photos, headlines, web replies) with *Clear Buckler's cache*, and a shortcut to Android's storage settings. Its list has **Unused apps** (below), **Cache** (apps holding more than 5 MB of cache, largest first) and **Largest apps** (the 15 biggest, app plus saved data). Each app in these lists opens its own page: Open, Force stop, Clear data and Turn off / Turn on (the last two pressed twice), Uninstall where Android allows it, and Android's app info ↗ (where *Clear cache* is). Buckler itself and the apps on the CLI's `never` list are never stopped, cleared or turned off; an app turned off here is recorded, so SHIELD clean-up's *Restore everything* brings it back. *Free cache space* there (or `buckler clean` from a computer) runs `pm trim-caches` over Network debugging and says how much it freed. Android clears only the part of each cache over that app's share, so an app's own page (its *Clear cache*) clears the rest. Sizes come from Android's storage records, under the same usage access as Apps.

**Unused apps** (Settings → Apps & storage → Unused apps): apps not opened for 14 / 30 / 60 / 90 days, from the TV's own usage records (nothing leaves the TV), busiest in the background first: how often each ran a background service and how much data it moved while off screen. Only apps with a launcher entry are judged; never Buckler, the keyboard, Home, accessibility services, apps installed within the period, or anything on the CLI's `never` list. Each opens the same app page, which also has *Keep*, taking the app off the list. Returning Home names newly unused apps at most once a week (*Tell me on Home*). `buckler unused` prints the same list from a computer and `buckler unused --apply [PACKAGES]` disables them, journaled so `buckler restore` brings them back. Usage access is one of the `buckler launcher grant-settings` grants, along with self-updates installing without a prompt.

**DNS:** `buckler dns status` (alias `get`) / `set --hostname …` / `off`.

Package id: `dev.solon.bucklerhome`. CLI and launcher both track **0.22.0**. Uses `INTERNET` for artwork, curated pack, GitHub updates, header weather/news, online screensaver photos and optional linked APIs; `ACCESS_NETWORK_STATE` for the Wi-Fi / Ethernet / VPN icons — no ads, no account telemetry. Release APKs are signed with `launcher/keystore.properties` (`storeFile`, `storePassword`, `keyAlias`, `keyPassword`; git-ignored) when present, otherwise with the machine-local debug key — OTA updates only install over an APK signed with the same key. Buckler also checks a downloaded update itself before installing it: it must be `dev.solon.bucklerhome`, signed with the installed app's key, or it is deleted. The release key's certificate SHA-256 is `releaseCertSha256` in `launcher/app/build.gradle.kts` (`scripts/release.py` reads it from there): an install signed with another key is not offered GitHub updates at all. Switching keys means one uninstall/reinstall. Backups are disabled (tokens live in encrypted prefs). Buckler ships a startup profile (its own code, plus the libraries'), installed by AndroidX ProfileInstaller, and once per version, a minute after it starts, asks Android to compile itself with that profile through its own adb link (the background dexopt job, so no restart), only if the TV already trusts that link and without ever raising the debugging prompt; otherwise Android does it in its overnight maintenance. After three minutes without a remote press the news ticker steps story by story instead of scrolling, and long Now Playing titles are cut short instead of scrolling, as every frame of motion repaints the whole of Home (on SHIELD, idle Home went from about 42% of a core to 21%); the next press brings the scrolling back. Feeds and artwork must be `https://` (checked in code); plain `http://` is allowed app-wide only because Multiview's sources (a Jellyfin server, an IPTV playlist, a camera on the home network) usually are, and Android cannot limit that to private addresses.
